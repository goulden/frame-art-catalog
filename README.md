# Frame art catalog

A small catalog of landscape, seascape and still-life paintings for a Samsung The Frame TV.
`catalog.json` lists each work with its title, artist, year, source and licence; `thumbs/` holds
a small tile image for each.

Every work comes from an open-access collection and is free to use:

- **The Metropolitan Museum of Art** Open Access (CC0)
- **National Gallery of Art** Open Access (CC0)
- **Cleveland Museum of Art** Open Access (CC0)
- A few works via **Openverse**, each carrying its own licence in `catalog.json`

Thumbnails are small downscaled copies for browsing. The full-size images stay at the museums
(`image_url` in the catalog). Each entry links back to its source page.

This is a personal project; it is not affiliated with any of the museums.
